# Java Stack & Queue

A Java project that demonstrates basic Stack and Queue operations using linked lists.

## Features

* Reverse a Stack using a Queue
* Remove odd elements from a Stack using another Stack
* Multiply Stack values that are divisible by 4
* Count positive, negative, and zero values in a Queue
* Interactive menu for selecting operations

## Technologies

* Java
* Data Structures
* Linked Lists
* Stack
* Queue

## About

This project was developed as part of a Data Structures course to practice working with Stack and Queue implementations and basic data structure operations.
